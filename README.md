# OnionServiceFingerprinting
The aim of this project is to collect data on a subset of 16,801 onion services via HTTP GET requests, analyze it for technological fingerprints using pattern matchin, and produce a report detailing the findings.

To reproduce findings from the report you also need:
- regular expressions for the technologies from: https://github.com/HTTPArchive/Wappalyzer
- onion addresses: https://ahmia.fi/
